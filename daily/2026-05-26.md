### 两篇合起来的核心逻辑

**Agent Wallet** 解决「Agent 能在链上做什么」——用 Session Key + Policy + Guard 三层把 Agent 的行动空间锁死。

**Machine Payment** 解决「Agent 能在链上花多少钱」——用 Budget + Quote + Payment Intent 三层让每一笔付款都可追溯、可限制。

两篇合在一起是一条完整链路：

```
用户设 Budget + Policy
  → Agent 收 Quote，检查预算
    → Guard 校验交易（地址白名单？金额超限？）
      → Simulation 预演结果，翻译成人话
        → Human Check 分层确认（小额自动 / 中额模拟+确认 / 高风险必须展示）
          → Smart Account 执行
            → Receipt 留下凭证
              → Revocation 随时可关
```
