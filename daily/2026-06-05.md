### 2. 🔴 Go x402 server — 最小可用版本（2–3 小时）

写一个 Go HTTP server，实现 x402（ERC-7725）协议的最小版本：

```
请求来了
  → 检查 Payment-Proof header
  → 没有 → 返回 402 + JSON body（付款信息）
  → 有 → 验证 tx hash（去 etherscan 查 / 本地 mock）
  → 通过 → 返回数据
```

**最小版本先不接链**——返回 402 就行，数据先 mock。付款验证后续再加。

**目标**：
- [ ] Go server 跑在 localhost:8080
- [ ] `curl localhost:8080/data` → 返回 402 + JSON
- [ ] `curl -H "Payment-Proof: tx_0x123" localhost:8080/data` → 返回数据（先 mock 验证）
