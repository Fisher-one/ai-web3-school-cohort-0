## 评委问题准备

已经通过模拟问答验证过的论点：

1. **「Go server 不是 Agent」** → 是「具有独立经济身份的自主服务」，和调 Stripe API 的区别是：它自己持有钱包、自主验证付款、没有中间人
2. **「CAW vs approve+transferFrom」** → 信任边界位置不同：CAW 的约束在 Agent 代码之外，防止 prompt injection 绕过权限
3. **「合法浪费攻击」** → 已知漏洞，rate limit + tx_count 是第一道防线，真正的修法是 session token 绑定请求方身份
4. **「x402 生态不成立怎么办」** → CAW Pact 信任边界模型独立于支付层，即使 x402 不普及，Agent 预算控制问题今天就存在
